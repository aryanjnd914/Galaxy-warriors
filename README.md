# ORBIT-GUARD — Space Debris Mission Control

AI-powered space debris tracking and removal planning system running on Raspberry Pi 4 edge node.

## Features
- Real-time debris risk scoring using orbital mechanics
- Interactive orbital simulation with removal missions
- AI threat assessment report with PDF download
- 100% offline capable

## Tech Stack
Python, Flask, scikit-learn, Chart.js, ReportLab

## How to Run
source venv/bin/activate
python3 app.py
Open http://localhost:5000

## Pages
- / — Mission Control Dashboard
- /simulation — Orbital Simulation
- /report — AI Threat Assessment Report
